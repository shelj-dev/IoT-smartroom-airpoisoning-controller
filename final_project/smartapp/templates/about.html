About This Project


This Gas Monitoring System is designed to detect hazardous gases using the MQ-2 sensor and provide real-time alerts to ensure safety.


The system continuously monitors gas levels and displays live readings, graphical analysis, and historical logs through an interactive web dashboard.


In case of dangerous gas levels, the system triggers visual and audio alerts to notify users immediately, helping prevent accidents and ensure timely action.
